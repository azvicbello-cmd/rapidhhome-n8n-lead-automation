# Portfolio copy

## Title
n8n Lead Qualification & Instant Response Automation

## Role
Automation Engineer / n8n Workflow Developer

## Short description
Built and tested an end-to-end n8n lead-response workflow for home-service businesses. The system accepts leads through a webhook, normalizes and scores each inquiry, routes leads into HOT/WARM/COLD paths, sends instant Telegram alerts for urgent leads, retries failed notifications, captures errors, and returns structured API responses.

## What this proves
- Webhook/API intake
- JavaScript transformation and scoring
- Branching and routing logic
- Notification integrations
- Retry and failure handling
- Production-style webhook responses

## Current limitation
The public demo uses deterministic scoring rules rather than an LLM. AI-based qualification can be added as an optional extension.
